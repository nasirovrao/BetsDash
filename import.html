Импорт ставок

Загрузи таблицу Excel (.xlsx/.xls) или CSV — сайт сам разберёт колонки и разложит ставки по полям. Импорт идёт в канал, выбранный ниже.

1Файл

Файл Excel (.xlsx/.xls) или CSV. Ведёшь историю в Google Таблицах? Ниже — как выгрузить её в подходящий файл за пару кликов.

Перетащи файл сюда — или нажми, чтобы выбрать
.xlsx, .xls, .csv
Как импортировать из Google Таблиц
  1. Открой свою таблицу на docs.google.com
  2. Если ставок несколько листов — переключись на нужный лист (импортируется только тот, что открыт сейчас)
  3. Сверху меню: Файл → Скачать
  4. Выбери Microsoft Excel (.xlsx) — файл скачается на компьютер/телефон
  5. Перетащи этот файл в область загрузки выше (или нажми на неё и выбери файл)
Почему нельзя просто вставить ссылку? Google не разрешает браузеру напрямую читать таблицу по ссылке (ограничение безопасности на стороне Google, не наше) — поэтому надёжный путь только один: скачать файл и загрузить его сюда, как обычный Excel.
